## 2. Shared pedagogical architecture

1. **Laddered credential.** Course-plus-exam entry level, then a stand-alone exam level, then higher tiers. Each rung is a hard prerequisite for the next. Passing unlocks eligibility to apply for the next rung. The ladder is described in three ways: required experience (recommended years in the field), a skill-set list, and target job roles.
2. **One curriculum spine, two depths.** One guide serves both levels. The higher level explicitly *includes and builds on* the lower one. Depth is shown side by side, not in separate books.
3. **Three-pillar competence model**, tested in separate sections on one day:
   - *Sensory* (blind deductive tasting on a fixed form)
   - *Knowledge + Business* (timed written theory with a math/business strand)
   - *Applied hospitality* (live, scripted role-play practical)
4. **Cross-informing sections.** The guide says outright that theory knowledge feeds both the tasting conclusions and the service answers. The practical also asks theory questions during the tasks.
5. **Conjunctive pass rule.** A minimum score in *each* section, and all sections must be passed in the same sitting. You can't make up a weak pillar with a strong one.
6. **Points-only scoring.** No deductions. Every line or question earns points, so leaving something blank is the main way to lose. The guides keep telling candidates to answer everything.
7. **Objective, pre-written assessments.** A central committee writes the exams ahead of time. Local examiners follow scripts with variants and don't improvise. Scoring uses pre-set observable criteria, multiple graders, and anonymous grading where possible.
8. **Feedback ritual.** Results go out at a same-day gathering, with feedback on strengths and areas to improve for each section. A minimum wait applies before a retake.
9. **Support layer.** Mock exams on the real delivery platform (unlimited attempts), free cohort prep sessions (several sessions over several weeks, with small-group breakouts), 1:1 mentor office hours, and a recommended reading list by beverage category.
10. **Integrity and inclusion frame.** Conduct rules, a device ban, recusal rights, an anonymous reporting line, an accommodations policy, and a candidate bill of rights. All of this is presented as part of the credential's credibility.

## 3. Curriculum matrix pattern (doc 3)

### 3.1 Block template (repeats ~50 times)
```
Subject Name: <SUBJECT>                      [optional flag: "higher level only"]
Learning Outcome — Level 1: "After studying this section, a student will…"
Learning Outcome — Level 2: "After studying this section, a candidate will…"
┌──────────────────────┬────────────────────────┬────────────────────────┐
│ Topic row label      │ Level 1 column         │ Level 2 column         │
├──────────────────────┼────────────────────────┼────────────────────────┤
│ …                    │ core fact / definition │ deeper / connective    │
│ …                    │ (filled)               │ (blank = not needed)   │
│ …                    │ (blank = not needed)   │ (filled)               │
└──────────────────────┴────────────────────────┴────────────────────────┘
(header repeats on every continuation page)
```
- **Learning outcomes:** 83 learning-outcome statements across the guide, about two per subject (one per level). Level 1 uses "student" and Level 2 uses "candidate". The verbs climb from *understand / recognize / locate* to *connect / distinguish / recommend / sell / calculate*.
- **Blank-cell rule:** A blank cell means "not essential at this level". Three kinds of rows result:
  - *L1 only*: foundations that L2 assumes you already know
  - *L2 only*: new depth such as classifications, vintages, producers, service and business
  - *Both*: L2 repeats L1 and then adds connections or more examples
- **Flags:** Some whole subjects are tagged "higher level only". In one subject the higher-level content is marked inline by color, so a single table serves both levels.

### 3.2 Subject families (high-level order)
1. **Foundations:** growing (with numbered "Factor 1…10" rows) → making (process steps)
2. **Places:** many regional blocks grouped by country, then sub-region. Old-world and new-world groups are kept apart.
3. **Style categories across regions:** sparkling, sweet, fortified
4. **Adjacent beverages:** beer, sake, spirits and liqueurs (a comparison grid), cocktails (a recall list for the higher level only)
5. **Business:** units and measures, vocabulary, then formulas with calculation rows

### 3.3 Recurring row taxonomy (regional template)
Approximate counts across the guide:

| Row label family | ≈count | Purpose |
|---|---|---|
| Geography: Location / Climate / Physical feature | 30–36 each | Where it is and why it matters |
| Soil | 36 | Link between site and outcome |
| Grape growing | 34 | Production decisions upstream |
| Winemaking | 33 | Production decisions downstream |
| Variety names (two families) | 32 each | What is made |
| Style | 31 | Resulting style |
| Law / appellations / classification / producers | ~45 combined | Rules, tiers, and the names that matter |
| Label terms / general terms | 32–33 | Vocabulary |
| Vintage | 33 | Year-to-year variation, linked to price |
| History & lore | 38 | Story and context |
| Service of beverage | 37 | Practical handling |
| Food & beverage pairing | 37 | Guest application |
| Business | 25 | Purchasing and pricing implications |

The rows run as a causal chain: **place → conditions → production → product → rules → names → story → serve → pair → sell**. This chain is the main reusable idea in the guide.

Non-wine subjects keep the same order but swap the row names: definition / ingredients / process / styles / classification / brands / service / pairing / business.

## 4. Assessment modality patterns

### 4.1 Day shape (one-day, sequential)
```
Check-in (ID + device check) → Briefing → [Sensory, ~45 min] → [Theory, ~35–40 min]
→ staggered individual [Practical slots, ~15–20 min each] across midday/afternoon
→ Results reception + feedback (end of day)
```
The two group, seated exams run back to back in the morning. Practical times are handed out at the end of theory. Everyone comes back together at the end for results.

### 4.2 Sensory exam (structured blind-tasting form)
- A small fixed set of samples split evenly across two families, done in one timed block. The guide suggests a per-sample time budget and checkpoints at halfway and near the end. The form auto-submits when time runs out.
- **Workflow:** paper scratch grid → transfer to the digital form → write the conclusion and sales line.
- **Examinable universe:** a published closed list of items and allowed origins (doc 2), each with style or production qualifiers. Candidates can prepare against a bounded set.
- **Form taxonomy (doc 5):**

| Section | Response type |
|---|---|
| Header | Name; instruction: every line must be answered |
| Appearance | Single forced choice from 3 ordinal options |
| Primary character (fruit) families | Yes/No per family + **conditional fill-in** ("if Yes, name one specific; if No, write *None*") |
| Condition modifiers (separately for nose and palate) | Pick **1–2** from a fixed set of about 8 |
| Secondary character families | Yes/No per family. A side rule says to mark Yes only if the character is *important to identity*. Nose and palate are combined |
| Structure | Binary rows + 4-point ordinal scales (low/med-/med/med+/high type) |
| Conclusion: identity | Pick 1 of **6 options listed for that exam** (from the published list) + "explain why" box |
| Conclusion: climate | 3-option ordinal + "explain why" |
| Conclusion: origin | Free recall (country) |
| Conclusion: age | 3 bands |
| Guest translation | "Sell it in ≤2 sentences" |

- **Teaching around the form:** a fully filled-out sample grid, a list of easily confused comparison pairs to practice, "why" prompts that must cite evidence from earlier rows, a self-consistency check (does the description support the conclusion?), and "trust structure" as a rule of thumb.

### 4.3 Theory exam (timed written)
- About 45 items in under 40 minutes, roughly 50 seconds each, on a digital platform with a built-in calculator. No deductions.
- **Item formats:** multiple choice, short answer, simple business math, matching (one-to-one from a larger distractor list), ordering/ranking, map identification, label reading, style recognition, and **error correction** (finding mistakes on a mock beverage list).
- **Level contrast technique:** the same topic is shown as a Level 1 item (recognition, multiple choice) next to a Level 2 item (recall, ordering, or naming a component). Same topic, harder thinking.
- **Business strand:** units and conversions, servings per container, cost-percentage logic, a period cost-of-goods formula, margin reasoning, and multi-step event-demand word problems.

### 4.4 Live practical (scripted role-play)
- A mock restaurant. A host role checks candidates in, checks their tools, and gives the instructions. **The instructions themselves count as part of the test**, and note-taking on paper is allowed. Each candidate gets a table with an examiner playing the guests. The examiner keeps time.
- **Task bank:** technical service (opening and pouring formats, flights), recommendation and pairing with stated reasons, recall of producers and years, recall of mixed-drink builds, recognizing adjacent-category brands.
- **Scoring cues:** listen, repeat back and confirm the order, stay hospitable when unsure, mind the guest's space, and include a specific identity triple (maker + year + origin) for full credit.
- Pre-written scripts with several variants keep it fair.

## 5. Scaffolding patterns worth reusing (as patterns, not content)

1. **Two-column depth matrix** with blank cells as explicit scope signals.
2. **Paired learning outcomes per subject**, with verbs that climb from recognize to recommend/sell.
3. **Causal row chain** (place → process → product → rules → story → serve → pair → sell) repeated in every unit. Students learn one template and apply it everywhere.
4. **Closed, published examinable list** for the sensory exam, so practice is bounded.
5. **Forced-choice + conditional fill-in + "explain why"** form design: one point per line, "None" instead of blank, evidence-based reasoning, and a short guest-facing sentence at the end.
6. **Confusable-pairs drills** for comparing and contrasting.
7. **Same-topic, two-level item pairs** to show what "harder" means.
8. **Error-correction items** built on realistic documents (menus or lists).
9. **Business math woven through** the curriculum rather than kept separate.
10. **Scripted role-play with a host who briefs**, where listening and confirming are scored.
11. **Conjunctive pass rule + same-day feedback ritual + minimum retake gap.**
12. **Preparation ecosystem:** mock exams on the real platform, cohort prep sessions with breakouts, mentor office hours, a reading list.
13. **Fully worked sample answer** for every form.
14. **Integrity and inclusion charter** as part of the brand (candidate rights, recusal, accommodations).

## 6. DO NOT COPY (hard list)

Do **not** reproduce, paraphrase, adapt, or closely imitate any of the following from the CMS-A documents:

- **Any prose:** purpose statements, policy text (cancellation, conduct, dress, devices, ethics, anti-racism, non-discrimination, integrity, bill of rights), exam descriptions, preparation advice, or "keys to success" wording.
- **Learning-outcome sentences** and the guide's sentence frames, such as its "After studying this section…" phrasing. Write new frames.
- **Content cells:** definitions, facts, region/sub-region/appellation lists, soil-to-region pairings, classifications and tiers, producer lists, vintage guidance, history items, pairing examples, service specifics.
- **The examinable-items list** (varieties × regions × qualifiers) or its layout, column wording, and qualifier style.
- **The tasting grid's labels and option sets:** its section names *as worded*, descriptor groupings, condition-modifier word list, structure-scale labels, age bands, instruction lines, and sales-line prompt. Build our own taxonomy from scratch.
- **Sample questions** (theory, matching, map/label, business math), **sample filled-in grids**, sample names, and sample sales lines.
- **Exact day-schedule times, durations, item counts, pass percentages, retake intervals, and prep-program sizes** as published rules. Set Sip Studies numbers on their own merits.
- **Cocktail list, brand examples, reading list, resource names**, and the CMS-A credential names (Introductory / Certified / Advanced / Master Sommelier), "Deductive Tasting Method", "Business of the Sommelier", "Maître d'" role framing, and logos, colors, or trade dress.
- **Any implied affiliation.** Sip Studies must never suggest it is endorsed by, equivalent to, or prepares for CMS-A credentials unless that is cleared legally.

**Allowed:** the general ideas listed in Sections 2–5 (laddered levels, a multi-pillar exam, depth matrices, forced-choice forms, role-play practicals, conjunctive passing). Ideas and formats like these are common across professional certification and are not protected expression.

## 7. Proposed Sip Studies original curriculum skeleton

### 7.0 Brand frame
- **Mission:** beverage education + entertainment + AI, tied to water accessibility (**"Water to Wine"**).
- **Pillars:**
  - **Sip Studios (Teach)**: Ai Winecast, **Ai Edu** *(home of this curriculum)*, Ai Contracting
  - **Somm Support (Engage)**: clean-water accessibility, disaster relief, tech for disadvantaged communities. *This is the charitable through-line of every level.*
  - **Ai RnD (Learn)**: research in tech, science, and data (desalination, the LLM beverage archive), Learn/Engage/Teach marketing, finance
- **Core values (used as rubric dimensions):** Culture · Credible · Catalyze · Legacy
- **Ikigai anchors:** water and food access, kids' rights, climate, preserving beverage data. Strengths: beverage education, community, pairings, communication, designing solutions.
- **Palette for course materials:** Clay `#914C2C` (headers / Level badges) · Deep Teal `#1A5552` (Water/Theory) · Mauve-Grey `#817985` (secondary text / blank-cell shading) · Mint Mist `#D8E6DA` (Sensory backgrounds) · Sand `#EDD4A8` (Practical / highlight)

### 7.1 Level ladder (Sip Studios › Ai Edu)

| Level | Name (original) | Format | Unlocks | Somm Support tie-in |
|---|---|---|---|---|
| L1 | **Source** | Course + short exam (seated, guided) | L2 | Each enrollment funds a set amount of clean-water access (amount TBD) |
| L2 | **Flow** | Stand-alone one-day exam: 3 pillars | L3 + Ai Edu peer-mentor role | Capstone: a water-access explainer for a partner community |
| L3 | **Current** | Advanced exam + field project | L4 | Field project with a Somm Support relief or tech partner |
| L4 | **Wellspring** | Mastery panel + published contribution to the LLM Beverage Archive (Ai RnD) | Faculty / Ai Winecast host | Leads one Somm Support initiative |

Each level page lists: who it's for · expected abilities · roles it prepares you for · how it gives back to Somm Support.

### 7.2 Three assessment pillars (renamed and rebuilt)

| Pillar | Sip Studies name | Format idea (original) | Value it scores most |
|---|---|---|---|
| Sensory | **The Tasting Map** | Blind flight of waters (and beverages at L2+) on a Sip Studies form | Credible |
| Knowledge + Business | **The Watershed Exam** | Timed digital mix: MCQ, matching, ordering, map/diagram reading, label/report reading, **water-report error correction**, impact and cost math | Credible + Catalyze |
| Applied hospitality | **The Table & Tap Practical** | Scripted role-play: a host brief (listening is scored) → serve and pair → explain a water-access fact to a "guest" in plain words | Culture + Legacy |

**Pass rule shape:** a minimum in each pillar, all passed in one sitting. Same-day **"Pour-Back" feedback circle**, with notes for each pillar under the four values. Retake after a cooldown period. (All numbers set by Sip Studies.)

### 7.3 Curriculum matrix: original subject spine
Each subject block uses a header, then **"Source" and "Flow" outcomes** written in Sip Studies' own frame (e.g. *"By the end, you can…"*), then a row × level matrix. Blank cells mean "not yet". Sip Studies adds a **third column, "Give-Back"**, that ties each row to Somm Support.

**Families and subjects (original):**
1. **Water Foundations:** The Water Cycle · Aquifers & Springs · Treatment & Filtration · Desalination (Ai RnD link) · Water Chemistry Basics (minerals, pH, hardness as *our* teaching topics)
2. **Waters of Place:** regional units on water sources (glacial, volcanic, artesian, municipal, rain-harvested), each running through the same row chain
3. **Beverage Bridges ("Water to Wine"):** water's role in brewing, distilling, coffee/tea, and winemaking. Pairing water with food.
4. **Access & Impact (Somm Support):** global access gaps · disaster-relief water logistics · appropriate tech for communities · kids' right to water · climate and drought
5. **Data & Legacy (Ai RnD):** reading water-quality reports · building the LLM Beverage Archive · preserving beverage knowledge
6. **Business of Hospitality:** pour and serving math, cost of water programs, impact-per-dollar math, menu and list auditing

**Original row chain (template for every place or style unit):**
`Source → Climate & Land → Journey (how it moves / is treated) → Mineral Profile → Taste Signature → Standards & Labels → People & Story → Serve → Pair → Price & Impact → Give-Back`

### 7.4 Sip Studies Tasting Map (original form design)
The *mechanics* are a common pattern. Every label and option set below is newly authored:
- **Clarity & Look:** 3-choice
- **Mouthfeel families** (e.g. *Silky / Crisp / Chalky / Effervescent*): Yes/No + "name one cue, or write *None*"
- **Mineral impressions** (Sip Studies' own list, e.g. *Salinity / Chalk-stone / Metallic / Flat*): Yes/No, with a "key to identity?" rule
- **Temperature & Finish:** pick 1–2 from Sip Studies' own word set
- **Structure dials:** our own 4-step scales (e.g. *Hush · Soft · Present · Bold*) for minerality, carbonation, and perceived pH
- **Conclusion:** source type (choose from a list published per exam) + "Why?" · region type (3-choice) + "Why?" · treatment path (free recall)
- **Guest line:** "Describe it to a guest in one sentence"
- **Give-Back line:** "One fact about this source's community or access"
- Scoring: points only, every line counts. A fully worked Sip Studies sample comes with every form.

### 7.5 Support ecosystem (original)
- **Mock exams in Ai Edu** with unlimited retries, plus an AI tutor (Sip Studios)
- **Winecast cohort sessions:** a short series with small-group breakouts, recorded for replay
- **Mentor "Sip Hours":** short 1:1 sessions with L3/L4 holders
- **Confusable-pairs drills** for water sources and styles
- **Same-topic, two-level question pairs** in every unit to show the Source vs Flow jump
- **Statechart / visual explainers** (pstack `/statechart` style) for process topics like treatment and desalination, tying into the 3×3 isometric video format
- **Sip Studies Learner Charter:** fairness, accommodations, anonymous grading, examiner recusal, feedback rights, all in original wording
