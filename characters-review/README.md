# Living characters

The 14-second portrait reel follows a porter, a harvester, the Village rower, a gull, a trout, a kingfisher and the Creek cooper. [Watch the MP4](living-characters-portrait.mp4)

The stills use the live scene geometry, lighting, water and postprocessing. A capture-only camera adapter set the close-up viewpoints. Desktop captures use High quality. Portrait captures use the automatic quality setting in touch emulation.
