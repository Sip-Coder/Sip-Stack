# Sip Studies · Ai Edu — Tasting Map Closed List
**Level:** 🟢 Source (L1) · **Status: PLACEHOLDER — Sip Studies original exam scope**

This list was written by Sip Studies for its own Source-level blind water tasting. It is not copied or adapted from any other program. The final exam list is set by Jonathan Yu before publication; any glass poured on a Source exam must come from the published list.

| Code | Water type | What a Source candidate should recognize |
|---|---|---|
| W1 | Glacial | Very light, crisp, low mineral |
| W2 | Volcanic spring | Silky, rounded, silica-forward |
| W3 | Artesian | Clean, smooth, balanced |
| W4 | Municipal treated (tap, rested & filtered) | Possible chlorine trace; varies by city |
| W5 | Rain-harvested (treated) | Very soft, featherlight |
| W6 | Sparkling mineral (natural carbonation) | Fine bead, mineral echo |
| W7 | Still mineral (higher mineral) | Present-to-bold minerality, salinity or chalk-stone |
| W8 | Purified / reverse-osmosis | Flat, very low mineral |
| W9 | Carbonated (added CO₂, low mineral) | Lively bubbles, little mineral |

**Open choices for Jonathan:** final list length (suggest 6–9), whether W8/W9 stay at Source or move to Flow, and how many glasses per flight (form assumes 3).
